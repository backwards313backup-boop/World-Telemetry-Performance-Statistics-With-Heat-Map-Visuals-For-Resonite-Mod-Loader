Advanced Performance Metrics Heat maps inside of Resonite worlds. This plugin allows you to visualize performance issues based on telemetry statistics inside of Resonite. The included metrics can be sorted and viewed by GPU/CPU/FILE SIZE/NETWORKING/DYNAMIC LIGHTS/DYNAMIC BONES/PHYSICS COLLISIONS/SLOTS/COMPONENTS/PROTOFLUX and probably more in the future.

This plugin requires Resonite Mod Loader.
